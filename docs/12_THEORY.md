# 12 — Theory

## 1. Working Theory of Writing

V1 uses the following model:

```text
Writing =
Meaning Selection
+ Reader-State Control
+ Language Realization
```

Editing is modeled as a separate correction process.

## 2. Meaning Selection

The writer must decide:

- what is actually worth expressing
- what tension or contradiction matters
- what final realization the text is moving toward

Fluent language without meaningful selection produces polished emptiness.

## 3. Reader State

Reader state is represented as:

```text
R =
Knowledge
+ Belief
+ Expectation
+ Emotion
+ Questions
```

A text is a sequence of state transitions:

```text
R0 → R1 → R2 → ... → Rn
```

## 4. Beat

A beat is not merely a paragraph or event.

A beat is a unit that changes reader state.

A useful beat should create one or more of:

- new knowledge
- reinterpretation
- changed expectation
- emotional movement
- new question
- resolved question
- deeper meaning

## 5. Progression

A text feels stagnant when language changes but reader state does not.

Conceptually:

```text
If R(i) ≈ R(i+1),
the beat is likely redundant.
```

This explains why many fluent AI texts feel repetitive despite surface variation.

## 6. Narrative Pull

Working formula:

```text
Narrative Pull =
Unresolved Question
+ Partial Resolution
+ New Question
```

The system should not always explain everything immediately.

Controlled incompleteness can sustain attention.

## 7. Immersion

Working model:

```text
Immersion ≈ Continuous, coherent reader-state transition
```

Immersion is weakened by:

- premature explanation
- unnecessary meta-commentary
- unsupported abstraction
- repeated summary
- abrupt perspective changes

## 8. Information Release

Narrative quality depends not only on what information exists, but when it becomes available.

```text
Same facts + different release order
→ different reader experience
```

This is why WIR models `reveal` and `conceal`.

## 9. Experience Before Concept

One high-value pattern is:

```text
Experience
→ Recognition
→ Concept
```

rather than always:

```text
Definition
→ Explanation
→ Example
```

The former often produces stronger immersion and insight in narrative commentary.

## 10. Meaning Gain

Each beat should answer:

> If this beat disappears, what specific understanding, feeling, or expectation disappears with it?

If the answer is "almost nothing," the beat is likely unnecessary.

## 11. Language Realization

The Writer's job is not to invent meaning.

It translates WIR into prose through:

- wording
- sentence structure
- paragraphing
- rhythm
- implication
- concreteness
- controlled abstraction

## 12. Editing

Editing is not generation again.

The preferred model is:

```text
Successful Draft
- Identified Failure
+ Minimal Correction
```

This motivates the Patch protocol.

## 13. Long-Term Hypothesis

If a reliable WIR can represent high-value writing cognition, then the same representation may later support:

- style extraction
- pattern libraries
- agent routing
- benchmark analysis
- process datasets
- distillation
- fine-tuning

The immediate project should test the representation before attempting those extensions.
