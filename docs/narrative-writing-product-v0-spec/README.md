# Narrative Writing Product V0

定位：Narrative Writing Workbench / AI 深度写作工作台。

核心不是 `Prompt → Text`，而是：

```text
Material → Intent → Generate → Read → Review → Patch → Accept
```

原则：
- User Objects != Engine Objects
- Draft 是界面中心
- AI proposes, user accepts
- Preserve before improve
- Patch != Rewrite
- Simple surface, deep control
- V0 不是 ChatGPT wrapper

实现前依次阅读 `product/00` 到 `product/10`，然后阅读 `PRODUCT_IMPLEMENTATION_TASK.md`。
