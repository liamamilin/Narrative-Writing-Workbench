# V0 Scope

本文件为 normative scope。

## In Scope

- Home
- Project
- New Task
- Writing Workspace
- Source input
- Writing Intent
- Reader Experience
- Generate Draft
- Draft editor
- Autosave
- Locks
- Review
- Local Patch
- Patch Compare
- Accept / Reject
- Writing Map（只读）
- Version History
- Version Compare
- Restore

## Out of Scope

V0 不做：
- RAG / vector DB UI
- Style Extraction
- Named-author imitation
- Pattern Library UI
- Collaboration
- Team workspace
- Native mobile app
- Autonomous long-novel generation
- Publishing integration
- Scheduling
- Fine-tuning / LoRA
- Marketplace
- Agent orchestration UI
- Knowledge Graph
- Timeline Engine
- Editable Writing Map

## Chat

Chat 不是 primary interface。

如果存在：
- secondary
- scoped to task
- 不能替代结构化 controls

## Platform

Primary：

```text
Desktop Web
```

## Priority Order

1. Material → Intent → Draft
2. Local Patch
3. Version Safety
4. Review
5. Writing Map
6. Project organization

遇到 scope/cost 压力，优先保护上面的顺序。
