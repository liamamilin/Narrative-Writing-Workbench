# Narrative Writing Product V0.1 — Quick Write Extension

This package extends Product V0 with:

```text
Topic → Meaning Discovery → Angle → WIR → Writer → Draft
```

It does not replace the original Product V0 specs.

The product now supports three starting states:

```text
1. Start with an Idea
2. Write from Material
3. Improve a Draft
```

Read this package after the original Product V0 spec.

Core principle:

> Quick Write should discover something worth saying before it tries to write beautifully.
