Recommended entry:

```text
What do you want to do?

[ Start with an idea ]
Turn a topic into a strong piece of writing

[ Write from material ]
Turn notes and sources into a draft

[ Improve a draft ]
Revise without rewriting everything
```

## Quick Write Screen

Keep it lightweight.

### Topic

```text
What do you want to talk about?

[ _______________________________________ ]
```

Example prompts:
- 为什么越想摆脱一个人，反而越像他？
- 谈谈失败。
- 为什么解释越多，故事有时越弱？

### Writing Mode

Default:

```text
Deep Narrative
```

Possible V0.1 options:
- Deep Narrative
- Clear Essay
- Fiction
- Free Writing

### Angle

Default:

```text
Auto Discover
```

Advanced:
- Angle
- Reader Experience
- Immersion
- Explicitness
- Intensity
- Length

### Optional Source

```text
[ Add Material ]
```

If source is added, explicitly transition toward source-grounded mode.

### Primary CTA

```text
Write
```

Not:
- Run Agent
- Generate WIR
- Discover Meaning

## Result

Open the same Writing Workspace used by source-grounded tasks.

Do not build a second editor.
