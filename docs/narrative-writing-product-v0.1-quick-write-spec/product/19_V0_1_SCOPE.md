# V0.1 Scope

This file is normative.

## In Scope

### Product

- Start with an Idea
- Quick Write screen
- topic-only task
- Auto Discover angle
- optional custom angle
- Writing Mode
- Reader Experience
- Length
- Write CTA
- Try Another Angle
- Rewrite Same Angle

### Engine

- Meaning Discovery
- 3–5 candidate angles
- selected angle
- handoff to WIR
- existing Writer
- existing Workspace
- existing Revision / Version system

### Basic Factuality UX

- lightweight fact-heavy topic flag
- Continue
- Add Sources

## Out of Scope

Do not add:

- web research engine
- automatic citations
- full RAG
- angle graph editor
- multi-agent debate
- style marketplace
- named-person style imitation
- autonomous topic feed
- trend discovery
- publishing
- collaboration
- editable Writing Map
- Pattern Library UI

## Priority

1. Topic → useful meaning
2. Meaning → coherent progression
3. Natural prose
4. Simple UX
5. Angle retry
6. Factuality warning
