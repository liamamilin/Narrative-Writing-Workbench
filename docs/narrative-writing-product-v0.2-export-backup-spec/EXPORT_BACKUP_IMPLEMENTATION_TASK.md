# EXPORT_BACKUP_IMPLEMENTATION_TASK

## Objective

让用户可靠带走当前文章，并能把本地工作区备份后恢复到独立位置。任何失败都不得改变当前正文或当前工作库。

## Milestones

| 里程碑 | 范围 | 完成证据 |
|---|---|---|
| E0 | 实施评审与扩展规格 | 范围、冲突决定、API、格式和风险已记录 |
| E1 | 文本导出服务 | 当前稿/指定版本的 md、txt 内容逐字正确，读操作无副作用 |
| E2 | 导出 UI | 待保存编辑先落库；冲突时不下载；工作台和版本页可操作 |
| E3 | 备份包 | 一致性 SQLite 快照、manifest、逐文件 hash、隐私排除 |
| E4 | 恢复预检 | 大小、格式、hash、schema、SQLite 完整性和必要关系检查 |
| E5 | 独立恢复 | 新目录原子落盘并可打开；当前库不变；失败清理临时文件 |
| E6 | 验收与报告 | 源码隔离、浏览器、往返恢复与损坏包测试通过 |

## Delivery Order

先完成 E0–E2 并独立提交。E3–E5 不改变导出 API，可在随后提交。E6 分别记录两段状态；备份恢复未通过前只能声明“文本导出完成”。

## Stop Conditions

- 不自动进入外部发布、云存储或同步。
- 不把数据库文件、密钥或内部执行记录塞进普通文章导出。
- 不为了项目级子集备份复制不完整的关系图；第一版使用全工作区快照。
