# Narrative Writing Workbench V0.4 — Revision Worklist

本目录是 Product V0 的增量规格，增加可逐项处理的修订工作单和确定性保留片段。它复用现有 Review、Patch、Accept/Reject 和 Version，不改变引擎内部 Critic/Patcher 语义。

权威文件：

1. [REVISION_WORKLIST_IMPLEMENTATION_TASK.md](REVISION_WORKLIST_IMPLEMENTATION_TASK.md)
2. [product/27_REVISION_WORKLIST_FLOW.md](product/27_REVISION_WORKLIST_FLOW.md)
3. [product/28_REVISION_WORKLIST_DATA_API.md](product/28_REVISION_WORKLIST_DATA_API.md)
4. [product/29_REVISION_WORKLIST_ACCEPTANCE.md](product/29_REVISION_WORKLIST_ACCEPTANCE.md)

发生冲突时，Product V0 决定 Review/Patch/Version 通用语义，本扩展只决定修订条目、正文锚点、保留范围及它们随正文变化的状态。
