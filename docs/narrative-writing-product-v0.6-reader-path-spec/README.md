# Product V0.6 读者路径检查

本规格是 Product V0 的实验性增量规格，分析当前实际正文如何逐段推进。

```text
Current Draft
→ Check Draft Path
→ Paragraph Functions + Knowledge Gains + Questions
→ Anchored Path Issues
→ Locate / Dismiss / Propose Patch
```

核心规则：

- “原定路径”来自生成计划；“稿件检查”来自当前正文，两者必须分开显示。
- 分析是模型对可能阅读效果的诊断，不冒充真实读者实验。
- 每段结果必须绑定当前正文的确切段落和逐字引用。
- 只有可靠定位的重复、推理跳跃、悬而未答或转折不清可以成为工作单。
- 问题修订复用 F03 ProposedPatch；接受前正文不变。
- 正文变化后旧检查过期，不能继续据此修订。

实现前依次阅读 Product V0，再读本目录实施任务与 `product/33..35`。
