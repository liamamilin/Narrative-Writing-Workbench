# Reader Path Flow

## Value Gate

独立入口必须能表达普通 Review 分数不能表达的信息：逐段主作用、该段增加的认识、提出的问题、回答的问题，以及问题之间的具体断裂。离线固定稿至少覆盖重复、推理跳跃、悬而未答；结果只复述“连贯性需提升”时停止开发。

## Check

用户在 Workspace 选择“稿件检查”并主动运行。第一版最多处理 80 个非空段落、正文 30,000 字符、单段 10,000 字符；超限明确拒绝。

每个非空段落显示：

- 段落号和原文；
- 主作用；
- 给理解增加了什么；
- 提出了什么问题（可空）；
- 回答了什么问题（可空）。

诊断问题类型限定为 `repetition / reasoning_gap / unanswered_question / unclear_transition`。每项显示可能影响和具体修改目标。

## Action

用户可定位、跳过或处理问题。处理只生成局部 ProposedPatch；一次只处理一项。接受后旧路径检查过期，用户可重新检查比较问题是否消失。第一版不自动宣称修改改善，也不连续自动修稿。
