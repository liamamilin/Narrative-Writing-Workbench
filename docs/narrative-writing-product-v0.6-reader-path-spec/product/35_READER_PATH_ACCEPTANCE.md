# Reader Path Acceptance

1. “原定路径”和“稿件检查”是两个明确视图。
2. 未运行时不伪造当前稿分析。
3. 每个非空段落恰好有一个路径步骤，原文逐字匹配。
4. 每个可操作问题有 revision/hash/段落/字符/quote 锚点。
5. 非法、遗漏或重复步骤使整轮检查安全失败；非法问题只被丢弃。
6. 页面说明结果是可能阅读效果的模型诊断，不是真实读者实验。
7. 定位能高亮相应正文；跳过不改正文。
8. 处理复用 ProposedPatch；Accept 前正文不变，Reject 后条目恢复待处理。
9. 正文变化后整轮过期，旧问题不可继续操作。
10. 备份严格校验 v6，并继续接受 v3/v4/v5 后增量升级。

真实效果验收另行记录问题命中、修改后人工改善、等待成本与用户理解；工程通过不等于模型诊断有效。
