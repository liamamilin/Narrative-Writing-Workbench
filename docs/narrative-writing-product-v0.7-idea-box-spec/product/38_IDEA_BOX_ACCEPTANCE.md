# Idea Box Acceptance

1. 本次生成候选与持久化选题箱有明确标题和不同操作。
2. 未收藏候选不写入 SQLite；收藏后刷新仍可读取。
3. 手工话题可收藏，标准化相同话题不会重复。
4. 可按关键词和状态过滤，可编辑备注、设为待写或归档。
5. 从未关联条目开始写时，Task 与 Idea 原子关联并变为已写。
6. 已关联条目打开原 Task，不重复创建。
7. 旧 localStorage 导入可重复调用且计数稳定；服务端未完整确认时不删除旧 key。
8. 清空浏览器存储后，SQLite 选题仍存在。
9. v7 备份包含 Ideas 并校验 task 关系；v3–v6 备份仍能恢复升级。
10. Quick Write 直接输入、建议、角度确认和生成保持回归通过。
