# AGENTS.md

1. Product V0–V0.7 是基础权威规格；本目录只增加文章分享。
2. 分享必须使用独立快照，不能把公开链接直接指向可变 Draft。
3. 公开响应采用白名单组装，不得序列化 Task、Draft 或 Version 整行。
4. token 至少来自 192 bit 随机数据；停止分享和删除 Task 后必须失效。
5. 创建分享前必须完成 autosave，并校验 expected revision。
6. 新表进入严格备份、旧版本兼容和关系校验。
7. 不增加账户、评论、协作、动态流、搜索索引或第三方发布平台。
8. 链接能否被他人访问取决于 Workbench 的部署地址；本机 `127.0.0.1` 链接只在本机有效。
