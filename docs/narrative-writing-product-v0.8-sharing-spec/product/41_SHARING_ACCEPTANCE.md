# Article Sharing Acceptance

1. 有正文时工具栏在“版本”后显示分享；创建前完成 autosave 并校验 revision。
2. 首次创建返回不可猜测链接、标题、正文快照、可选署名和摘要。
3. 公开 HTML 只显示白名单字段，不出现素材、目标、检查、保护、版本、模型、operation 或密钥。
4. 分享后继续编辑正文不会改变旧链接内容，工作台提示快照已经落后。
5. 更新分享版本创建新 token 并使旧链接返回 404。
6. 停止分享后公开 HTML 与 meta 都返回 404。
7. 删除 Task 或 Project 会删除分享记录；失败必须与其余删除一起回滚。
8. v8 备份包含分享快照并校验 Task/Draft 关系；v3–v7 备份仍可检查、恢复并升级。
9. 分享卡片可以预览和保存为 PNG；复制链接和系统分享在不支持时有回退。
10. 公开阅读页在桌面和窄屏 Safari 尺寸下保持单栏、可读、无横向溢出。
11. 本机地址明确提示只能本机访问；部署地址使用当前 origin 生成链接。
12. 原有生成、编辑、导出、版本、删除与备份测试保持通过。
