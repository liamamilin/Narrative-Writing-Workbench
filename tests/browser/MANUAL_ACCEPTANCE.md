目的：用真实人工操作确认原生中文输入法、长中文粘贴、多段选择和完整键盘流程。自动化已经覆盖 5,200 字剪贴板粘贴、合成 composition、段内/跨段 DOM 选择与提案范围，以及部分 Enter/Space/Escape 焦点路径，结果见 `.scratch/browser-report/results.json`；这些检查不能代替真实输入法和手工交互，本表必须由实际操作者填写，未执行项保持“待验”。

## 隔离启动

从仓库根目录运行：

```bash
python3 scripts/mock_server.py
```

打开终端输出的 `MOCK_URL`。该服务使用临时数据库、mock 引擎，不读取用户 settings 或数据库，不调用模型；按 Ctrl+C 后清理临时数据。
